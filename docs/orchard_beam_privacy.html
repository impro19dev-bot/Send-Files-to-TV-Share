Privacy

Send Files to TV: Share is a local utility. It does not ask you to create an account.

Files you pick

When you start sharing, the app reads the files you selected and serves them over your own Wi‑Fi to a browser you open. Those bytes stay on this iPhone except for the copies a device on your network downloads while the shelf is open. Closing sharing stops the temporary page. The app does not upload your files to a developer server.

Network

The app looks up this iPhone’s private address so it can show you a link. Local network permission is used only while sharing is on.

On this device

A preference records whether you have finished the primer so it is not shown on every launch. You can clear that flag in Preferences.
